## 三、实现优先级排序

### P0 紧急（影响基础使用）
1. 更多标注类型（对齐/半径/直径/角度）
2. 更多编辑命令（镜像/偏移/修剪/延伸/分解）
3. 打印页面设置+框选打印
4. 距离/面积查询

### P1 高优先级（室分核心）
1. 链路预算引擎（2G-5G各频段）
2. 材料表自动生成+导出Excel
3. 系统图自动生成
4. 馈线自动连接/路由
5. 2G-5G频段损耗参数配置

### P2 中优先级（提升效率）
1. AI自动布放天线
2. AI自动插入功分器/耦合器
3. 建筑图纸AI精简
4. 设备材料估算
5. 预算表
6. 跨格式兼容（天越/AIDP）

### P3 低优先级（完善体验）
1. 椭圆/多边形/样条曲线/填充/多行文字/表格
2. 阵列/拉伸/打断/倒角/圆角
3. 更多捕捉类型
4. 块功能完善（属性块/外部参照）
5. 专项场景工具（电梯/综合覆盖/漏缆）
6. 图纸内容自动生成（概要/风险/规范/图例）
7. 新手教程/操作手册

## 四、避免遗漏的开发流程规范

### 4.1 开发前（必须执行）
1. 从本文档提取对应模块的完整功能清单
2. 写成checklist，每项标注优先级
3. 对照规格书确认无遗漏
4. 与用户确认范围

### 4.2 开发中
1. 按checklist逐项实现
2. 每完成一项在checklist中标记
3. 遇到规格书中未明确的细节，主动调研或询问用户

### 4.3 开发后（必须执行）
1. 逐项核对checklist，未实现的明确标注原因
2. QA验证：不仅查bug，还要查"功能覆盖度"
3. 更新本文档的功能状态
4. 输出遗漏清单和下一步计划

### 4.4 定期检查
- 每个阶段结束时做一次全面的规格书对照检查
- 每月更新一次功能矩阵文档
- 每次用户指出遗漏时，立即补充到本文档
